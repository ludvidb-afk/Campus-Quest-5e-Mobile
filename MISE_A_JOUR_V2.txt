- 74 questions et 11 matières
- Mini-jeux, boutique, résidence et personnalisation
- XP, niveaux, jetons, missions et trophées
- Sauvegarde locale déjà présente sur l'appareil
- Fonctionnement hors ligne

INSTALLATION DE LA MISE À JOUR
1. Remplacer sur GitHub les fichiers fournis par ceux de cette mise à jour.
2. Attendre la publication de GitHub Pages.
3. Fermer complètement Campus Quest 5e sur le téléphone.
4. Rouvrir l'application. La sauvegarde existante est conservée.

Si l'ancien décor reste affiché, fermer puis rouvrir une seconde fois l'application afin que
le nouveau cache hors ligne prenne le relais.
